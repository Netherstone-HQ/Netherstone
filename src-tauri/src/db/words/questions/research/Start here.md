# Start here

This vault follows one question from sources to findings. The example asks whether taking notes by hand helps you learn more than typing them. Keep it as a guide, or clear it out and start your own.

## How it's laid out

- [Question](Question.md) says what you're trying to find out and what would count as an answer
- **Sources** holds one shard per paper, book or article: what it claims, how it got there and what you take from it
- **Findings** holds what you've concluded, each one linking to the sources behind it
- [Open questions](Open%20questions.md) collects what you still don't know

The How it connects drawing maps which sources support which findings.

## Working this way

Write a source shard as soon as you read something, while it's fresh. Keep your own thoughts under **What I take from it**, apart from what the source says. Link every finding to the sources behind it.
