Netherstone is an app for your documents, drawings and files. It saves them as Markdown files in a folder on your phone, called a vault.

Keep the vault in Netherstone's own storage, or in a shared folder, such as Documents, so other apps can open it too.

<ul>
<li>Write with a bar above the keyboard for lists, links, headings and colors</li>
<li>Add pictures, video, sound and files, take photos and record voice notes</li>
<li>Link documents to each other, tag them and see each one's outline</li>
<li>Make drawings and diagrams, in their own file or inside a document</li>
<li>Search the vault, and filter by tags, images, drawings and voice notes</li>
<li>Go back to an earlier version of a document, and restore deleted ones from the Trash</li>
<li>Export as a PDF, a Word file or a web page</li>
<li>Share text, links and files to Netherstone from other apps</li>
</ul>

Sync is optional. It goes through your own GitHub account and keeps the vault the same on a phone and a computer. Netherstone also runs on Windows, macOS and Linux.

The assistant is off until you set it up. It answers questions about your documents and suggests edits that you check before they apply. It works with a key from a cloud AI provider, or with a server you run on another computer.

The code is public under GPL-3.0.
